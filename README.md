# 宿舍管理系统 (Dormitory Management System)

## 🛠 技术栈
- Frontend: Vue 3 + Element Plus + Vite
- Backend: Java Spring Boot 2.7 + Spring Data JPA
- DB: MySQL 8.0

## 🚀 快速启动 (Docker)
1. 确保 Docker Desktop 已运行。
2. 在根目录执行：`docker compose up --build`
3. 访问前端：http://localhost:3001
   > 注意：Docker 部署模式下前端映射端口为 3001，以避免与本地开发端口 3000 冲突。
4. 访问后端接口：http://localhost:8080

## 📸 功能介绍
本系统包含完整的高校宿舍管理业务流程：

- **用户权限管理**
  - 支持管理员、宿管、学生三种角色。
  - 严格的权限控制（如宿管人员无删除权限）。

- **房源与分配**
  - **楼栋/房间管理**：支持多种房型（四人间、双人间等）及楼栋信息管理。
  - **入住申请**：新生入学申请、调宿申请审批流程。
  - **床位分配**：可视化的床位分配与管理。

- **生活服务**
  - **报修系统**：学生在线提交报修，宿管接单处理，状态实时更新。
  - **费用缴纳**：住宿费、网费等费用的账单生成与支付状态管理。
  - **卫生检查**：定期记录宿舍卫生评分与评价。

- **安防与考勤**
  - **出入记录**：记录学生出入楼栋的时间与方式（人脸/刷卡）。
  - **考勤管理**：自动统计晚归、缺勤等异常情况。
  - **安全巡检**：记录消防设施检查等安全维护记录。

- **公告通知**
  - 管理员发布重要通知，学生端实时查看。
